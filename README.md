# Space-invaders-game
A browser-based version of the classic Space Invaders game where the player controls a spaceship to shoot down alien invaders. Built with HTML, CSS, and JavaScript, it features smooth movement, shooting mechanics, and basic enemy logic. This project helped me understand DOM manipulation, event handling, and core game logic in JavaScript.
This project is a simple yet fun version of the classic Space Invaders game, built entirely using HTML, CSS, and JavaScript. The player controls a spaceship at the bottom of the screen and must shoot down waves of alien invaders moving from side to side at the top. The game includes smooth movement, shooting mechanics, and basic enemy logic. It's a great demonstration of how core web technologies can be used together to build interactive browser-based games.

Working on this project helped me strengthen my understanding of DOM manipulation, event handling, and game logic in JavaScript. It was also a fun way to bring a nostalgic arcade-style game to life using just front-end skills, and it sparked my interest in developing more interactive web applications.
